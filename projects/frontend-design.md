## 2026-10

### [hairline](https://github.com/lucasmarkes/hairline)
- 发现：2026-10-07
- 一句话：27 个会跟着指针动的等距线条插画，React 和任何 DOM 页面都能用。
- 摘要：npm 包 `@lucasmarkes/hairline`，零依赖、仅 ESM，提供卡片托盘、柱阵、分层窗口、键盘、终端、提交图等 27 个图形，统一用 `intensity` 控制反应强弱，支持明暗主题和 CSS 变量换色，也能用 shadcn 一键安装。它照顾了无障碍、减少动效偏好和服务端渲染（先占位不跳动），全页图形共用一个动画循环、静止时不耗资源。还附带 `hairline-create` 技能，可让 Claude Code、Cursor、Codex 等编码智能体按它的十条规则画出新图形。适合给落地页或产品首页做轻量的交互插画。
- 标签：`前端` `React` `动效` `插画` `skills`

### [React Bits](https://github.com/DavidHDev/react-bits)
- 发现：2026-02-16
- 一句话：开源的可定制动画与交互 React 组件库，用于打造有记忆点的网站界面。
- 摘要：React Bits 提供大量免费、可定制的 React 动画组件，覆盖文字动画、界面元素、微交互与背景等类型。组件依赖较少、支持按需裁剪，并可通过 props 或直接改源码调整样式。每个组件提供 JS-CSS、JS-TW、TS-CSS、TS-TW 四种变体，可复制到现代 React 项目中使用。
