## 用法

更新分类计数和最近新增：

```bash
python3 scripts/catalog.py index
```

校验日期倒序、字段、日期格式，以及全库 URL 是否重复：

```bash
python3 scripts/catalog.py check
```

推送和拉取请求会在 GitHub Actions 里自动运行 `check`。
